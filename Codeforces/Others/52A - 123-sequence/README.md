There is a given sequence of integers `a₁, a₂, ..., aₙ`, where every number is from 1 to 3 inclusively. You have to replace the minimum number of numbers in it so that all the numbers in the sequence are equal to each other.

## Input

The first line contains an integer `n` (`1 ≤ n ≤ 10⁶`). The second line contains a sequence of integers `a₁, a₂, ..., aₙ` (`1 ≤ aᵢ ≤ 3`).

## Output

Print the minimum number of replacements needed to be performed to make all the numbers in the sequence equal.

## Examples

**Example:**

```
9
1 3 2 2 2 1 1 2 3
```

**Output:**

```
5
```

## Note

In the example all the numbers equal to 1 and 3 should be replaced by 2.
